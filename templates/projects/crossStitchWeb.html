Cross Stitch Pattern Maker Website

Course Work

Skills: Design; HTML, CSS, JavaScript

Overview

This website was created for a class assignment in Programming Usable Interfaces. The focus of this assignment was to create a usable and functional website. This website is designed to allow the user to create new cross stitch patterns using the grid and the color picker. A major purpose of this assignment was to understand using libraries and their functionality for a project. The color picker utilizes two libraries, one for the search feature itself and one for the auto-complete functionality of the search. This project is a proof of concept meant to highlight experience with HTML, CSS, and JavaScript and the general development process. As part of this assignment, our class underwent design and code reviews to demonstrate understanding of the process. If you would like to view the website, please click on this link.
